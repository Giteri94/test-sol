# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those
roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `Tri des besoins` | Maintainer needs to evaluate this issue |
| `needs-info` | `Besoin d'info` | Waiting on reporter for more information |
| `ready-for-agent` | `Prêt à dev` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `Attention requise` | Requires human implementation |
| `wontfix` | `On fera pas` | Will not be actioned |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the
corresponding label string from this table.
